# AMO Listing Description - Quick TAB Launcher by Bonn

## Short description (for manifest / AMO summary, max 132 chars)

Spotlight-style command palette to search tabs, bookmarks, and history with a keyboard shortcut.

## Full description (for AMO listing page)

Press Ctrl+Shift+Space to open a search panel over any page. Type a few characters to find open tabs, bookmarks, and pages from your history.

**Fuzzy search**
Results come from tabs, bookmarks, and history, ranked by fuzzy matching. You don't need to type exact titles.

**Command palette**
Type ">" to access quick commands: sort tabs, close duplicates, mute tabs, pin tabs, and more.

**Recent tabs**
Open the launcher with an empty search to see your most recent tabs and recently closed tabs. Restore closed tabs with one click.

**Duplicate detection**
If you have duplicate tabs open, a banner lets you close them all at once.

**Grouped view**
Press Alt+G to group results by domain. Useful when you have dozens of tabs open.

**Full-text search (optional)**
Enable full-text search in settings to search inside the content of your open tabs, not just titles and URLs.

**Close tabs from results**
Hover over a tab result and click the close button to close it without leaving the launcher.

**Works everywhere**
The launcher is an overlay that works on any web page. On privileged pages (about:, extensions) it falls back to a popup.

**Keyboard-first**
Navigate results with arrow keys, Enter to open, Shift+Enter to open in the current tab, Escape to close. No mouse required.

**Customizable**
Number of results, history range, debounce speed and other options can be changed in the settings page.

**Privacy**
No data leaves your browser. No network requests, no analytics, no tracking.

Available in Italian and English.
